# HELLCOM Logistics Website

Custom Next.js starter for HELLCOM Logistics.

## Run locally

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this repository to GitHub and import it into Vercel. Vercel auto-detects Next.js.

## Before launch

- Replace demo phone/WhatsApp placeholders.
- Connect the quote form to email/CRM.
- Add final approved logo assets.
- Add real company address and service coverage.
- Add real customer proof only after it exists.
